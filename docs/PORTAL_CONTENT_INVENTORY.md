### Unresolved editorial issue — Book 1 cover

This issue is unresolved. The original PDF has not been edited or replaced.

The Book 1 cover says the book is for Classes 6–8 and 9–10, and that Book 1 is for both groups. The same PDF’s model-test footer says Group-1 (Classes 6–8). The cover needs clarification or correction by the organisation before Book 1 is published. Until that happens, the portal keeps the launch mapping below and does not give Book 1 to Classes 9 or 10.

The Book 2 cover says Classes 9–10 only, and the model-test footer says Group-2 (Classes 9–10).

The launch rule used by the portal, matching the requested examples, is:

- Book 1: Classes 6, 7 and 8.
- Book 2: Classes 9 and 10.

A Future Tech Class 9 account therefore does not receive Book 1. That is held back because the Book 1 cover and the Book 1 footer do not say the same thing. Publication stays at **awaiting approval** until the organisation resolves it.

## What was not turned into mock tests

Both PDFs contain practice questions and a model test paper inside the book. Their text layer repeats and overlaps, so those items were not copied into the question bank. Students read the original PDF. The five official mock tests for each book come only from the Word booklets.

## Access rule

A signed-in student receives only books and tests whose stream and class list contain the stream and class stored at registration, whose payment is verified, and whose publication status is published. Dashboard hiding is not the control. The file and test routes apply the same check. Stream and class cannot be changed by a student request. Staff corrections write an audit event and do not carry an earlier payment onto a different book.
